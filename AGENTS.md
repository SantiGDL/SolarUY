Instrucciones del proyecto

## Contexto

SolarUY es una aplicación de gestión de parques solares desarrollada
como prueba de concepto para el Taller .NET.

Contempla la administración de parques, nodos y paneles, tareas de
mantenimiento, monitoreo de generación y consulta de datos históricos.
La interacción con el inversor se representa mediante un mock o simulador.

El proyecto utiliza Blazor Web App con Interactive Server y se organiza
como un monolito modular, con los módulos Usuarios, Parques, Tareas
y Mediciones.

Esta descripción expresa el alcance general del proyecto, no implica
que todas las funcionalidades estén implementadas.

## Reglas generales
